My research sits at the intersection of natural language processing, multi-agent systems, and reinforcement learning. I'm especially interested in how multiple specialized LLM agents can collaborate on complex language tasks, and how reinforcement learning can be used to optimize that collaboration rather than leaving it to hand-written prompts and fixed pipelines.

Current directions

Multi-agent pipelines for long-document summarization

Splitting summarization into specialized roles — selecting what matters, drafting, critiquing, refining — and studying how those agents should be coordinated when a document is far longer than any single context window.

Reinforcement learning for LLM agents

Using RL to fine-tune agent behavior and coordination policies, so that a system learns which agent to call, on what input, and when to stop — instead of following a fixed script.

Adaptive intelligent tutoring

Sequencing practice problems with deep RL so that the next question matches a student's current mastery, combined with LLM-generated hints and explanations.

Explainable and trustworthy AI

Making model decisions inspectable — through feature attribution, rule-based explanations, and failure detection — so multi-agent systems can be debugged and trusted, not just benchmarked.
